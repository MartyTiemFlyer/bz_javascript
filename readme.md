# База знаний

Веб-приложение для создания, хранения и просмотра технической документации в формате Markdown.

## Возможности

- **Структура базы знаний:** категории, страницы, боковая панель навигации и хлебные крошки.
- **Редактирование контента:** создание и изменение категорий и страниц через веб-интерфейс.
- **Предпросмотр Markdown:** отображение форматирования в реальном времени непосредственно в редакторе.
- **Работа с файлами и изображениями:** загрузка вложений, вставка скриншотов из буфера обмена и изменение размера изображений. Есть доступ ко всем загруженным файлам в табличном виде (Все файлы)
- **Поиск:** полнотекстовый поиск по заголовкам и содержимому страниц с сортировкой по релевантности, контекстными фрагментами и подсветкой совпадений.
- **Оглавление:** автоматическая генерация по заголовкам статьи с подсветкой текущего раздела.
- **Экспорт в PDF:** возможность сохранить страницу в PDF через окно печати браузера.
- **Авторизация:** защита функций редактирования с помощью пароля и сессий.
- **Управление вложениями:** просмотр и удаление загруженных файлов.
- **Резервное копирование:** скрипт для создания дампа базы данных и архива загруженных файлов.

## Технологии

- Node.js 20
- Express.js
- EJS
- PostgreSQL
- Markdown-it
- Docker и Docker Compose

## Запуск

Для запуска необходим установленный Docker с поддержкой Docker Compose.

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/MartyTiemFlyer/bz_javascript.git
   cd bz_javascript
   ```

2. Настройте переменные окружения в `.env` согласно конфигурации проекта.

3. Соберите и запустите приложение:

   ```bash
   docker compose up --build
   ```

4. Откройте приложение в браузере:

   http://localhost:3000

   Порт может отличаться в зависимости от конфигурации Docker Compose.

## Редактирование страниц

Для создания и редактирования категорий и страниц необходимо авторизоваться. В редакторе доступен исходный текст Markdown и его предварительный просмотр. Изображения и другие файлы можно загружать непосредственно из интерфейса редактирования.
Для редактирования (и администрирования) создайте пароль и положите его в `.env`. В данной реализации используется переменная `EDIT_PASSWORD_HASH`.
